# dsh-kanban

Канбан-доска для DeepSeek Harness: отдельная доска у каждого проекта, задачи с черновиками и статусом «Можно делать», карточки с агентами, субагентами и фоновыми job, детали задачи в правой панели приложения и инструменты для агента.

## Возможности

- **Доска на каждый проект.** Данные лежат в `<workspace>/.dsh-kanban.json`; переключение проекта переключает доску.
- **Пять колонок:** Беклог → Можно делать → В работе → На проверке → Готово.
- **Черновики.** Новая задача создаётся в беклоге как черновик: её можно долго редактировать, она не попадает агенту. Кнопка «Можно делать» переводит задачу в To Do и запускает агентскую сессию.
- **Карточки с метриками.** На карточке видны приоритет, метки, последняя активность, счётчики: агенты (включая субагентов), субагенты, фоновые job.
- **Детали в правом sidebar.** Клик по карточке открывает вкладку «Задача» в правой панели приложения: заголовок, описание, приоритет, метки, статус, история, перемещение, удаление, переход в сессию задачи.
- **Агентский workflow.** Хост-часть регистрирует инструменты `kanban_*`, добавляет агенту секцию системного промпта и ведёт сессию на каждую задачу. Агент не может трогать черновики и не может самовольно переводить задачи в To Do или закрывать из Review.
- **Живое обновление.** Доска опрашивает API каждые 3 секунды; карточки подсвечиваются при изменениях, пришедших от агента.
- **Оформление Harness.** Светлая и тёмная тема через токены `--dsw-alias-*`, адаптивная сетка колонок, drag-and-drop с клавиатурой и `prefers-reduced-motion`.

## Установка

```sh
dsh plugin --profile desktop add github:fourclub/dsh-kanban
```

Или из локальной папки:

```sh
dsh plugin --profile desktop add /path/to/dsh-kanban
```

После установки перезапустите Harness. Вкладка «Канбан» появится рядом с Chat и Trajectory; иконка канбана появляется у проекта в левом sidebar.

## Колонки и статусы

| Колонка | Что означает | Кто двигает |
|---|---|---|
| Беклог | Черновик/идея; агент не трогает | человек |
| Можно делать | Готова к работе, агент может взять | человек ставит «Можно делать» |
| В работе | Агент подтвердил взятие | агент |
| На проверке | Нужно решение или ответ человека | агент |
| Готово | Задача завершена | агент (если разрешено) или человек |

## Инструменты агента

`kanban_get` · `kanban_get_item` · `kanban_create_item` · `kanban_update_item` · `kanban_move_item` · `kanban_next` · `kanban_assign` · `kanban_set_status` · `kanban_delete_item` · `kanban_set_code`

`kanban_next` берёт первую готовую задачу из «Можно делать», переводит её в «В работе» и привязывает к текущей сессии.

## Хранение данных

- Один JSON-файл на проект: `<workspace>/.dsh-kanban.json`, схема версионируется и мигрирует автоматически; повреждённый файл резервируется и заменяется пустой доской.
- Данные не покидают проект; клиент обращается только к same-origin маршруту `/api/kanban` этого плагина.

## Разработка

```sh
npm install
npm run typecheck
npm test
npm run build   # пересобирает lib/client.js (артефакт коммитится)
```

CI не требуется: артефакт клиента и хост-код лежат в репозитории.

## Совместимость

- DeepSeek Harness Web/Desktop с поддержкой клиентских плагинов (`dsh.client`).
- Правая панель использует сервисы `sidebarRight`/`sidebarRightTabs`; если их нет, детали открываются запасным диалогом.
- Node.js ≥ 20 для сборки.
